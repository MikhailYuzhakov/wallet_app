**Wallet Application** - REST-приложение для пополнения или снятия денежных средств с баланса счетов. Приложение построено по микросервисной архитектуре, предусмотрено три микросервиса - асинхронное приложение, синхронное приложение и сервер конфигурации.
В приложении предусмотрена возможность миграции базы данных с помощью liquibase, реализована обработка ошибок при следующих ситуациях: не найден кошелек, недостаточно средств, отрицательная сумма, некорректная операция, некорректный UUID кошелька и
некорректнный формат тела запроса JSON. В приложенииях реализованы тесты для эндпоинтов, тесты для различных исключений. Было проведено нагрузочное тестирование приложения с помощью JMeter, в результате тестирования синхронное и асинхронное приложения
справились с нагрузкой 5000 RPS (POST запросы на изменение баланса кошелька). Развертывание приложения производится с помощью docker-compose, создается 4 контейнера: БД, сервер конфигурации, синхронное приложение app-wallet, асинхронное приложение app-wallet-reactive.
С помощью переменных enviroments (docker-compose.yaml) предусмотрена возможность настройки параметров приложения и базы данных без необходимости пересобирать контейнеры.

**Эндпоинты:**
1. POST-запрос на изменение баланса кошелька.
POST /api/v1/wallet
```
BODY 
{
    "walletUUID": "e22522ff-b624-48b5-97d8-ab7d89d3d2f4",
    "operationType": "DEPOSIT",
    "amount": "1"
}
```

3. GET-запрос на получение баланса кошелька.
GET /api/v1/wallet/e22522ff-b624-48b5-97d8-ab7d89d3d2f4

**Описание модулей**:
1. app-wallet - Spring MVC синхронное веб-приложение. Запускается на порту 8080.
2. app-wallet-reactive - Spring WebFlux асинхронное веб-приложение. Запускается на порту 8081.
Используют конфигурацию с сервера Spring Cloud Config, создают таблицу wallets, заполняют её данными с помощью скриптов liquibase.
3. config-server - сервер конфигурации Spring Cloud Config. Использует git для обновления конфигурации. Запускается на порту 8888.
4. init-db - директория содержит SQL-скрипт для создания БД wallets внутри контейнера wallets-db.
5. docker-compose.yaml - описание структуры и состава контенейнеров Docker.

**Запуск:**
1. Загрузить содержимое репозитория.
2. Загрузить содержимое репозитория (https://github.com/MikhailYuzhakov/wallet_app_config/tree/master) с конфигурацией в директорию config-server/src/main/resources/configs.
3. Проверить, что порты 8888, 5432, 8080, 8081 на хосте свободны.
4. Заупстить контейнеры командой docker-compose up -d.
